# 🧠 AI Text Intelligence Dashboard

An interactive Natural Language Processing application combining traditional NLP techniques with Transformer-based AI.

## 🚀 Live Demo

👉 https://masmi-ai-nlp.streamlit.app/

## What It Does

- Performs sentiment analysis
- Uses a pretrained DistilBERT Transformer
- Performs Named Entity Recognition with spaCy
- Extracts keywords
- Analyzes word frequency
- Calculates TF-IDF
- Measures cosine text similarity
- Performs tokenization and lemmatization
- Detects stop words and parts of speech

## AI / NLP

The project compares traditional NLP methods with modern Transformer-based sentiment classification.

## Technologies

Python • NLP • spaCy • DistilBERT • Hugging Face Transformers • TF-IDF • scikit-learn • Plotly • Streamlit
